# Organization video plan

**Audience:** a first-time clinic platform administrator. **Angle:** one platform, multiple clinics; distinguish organization from branch and show the create-clinic process. **Visuals:** illustration based on source UI labels and Harbor teal/coral theme, plus real repository logo. Fictional names and usage data; not a real screen recording. Plan values are examples from the snapshot seed, not current offers. **Format:** 1280×720, 30 fps, 22 seconds. Silent narration; music and SFX.

| Time | Beat |
|---|---|
| 0–3.5 | Hook: ek app, kai clinics |
| 3.5–7 | Platform Admin Organizations list, illustrative rows |
| 7–11 | Create clinic form, simulated click, provisioned entities |
| 11–14.5 | Example plan cards and trial |
| 14.5–18 | Two example clinics, organizationId scope; isolation needs verification |
| 18–22 | Basic next steps and brand |

Music: Sascha Ende, ende.app, Happy Beats / Business Moves Vol. 1, CC BY 4.0. Bundled /brag CC0 sound effects. Approx. 120 BPM; cuts at half-second boundaries. The video uses a custom Pillow/FFmpeg renderer, not the Hyperframes pipeline or a literal /brag execution.
